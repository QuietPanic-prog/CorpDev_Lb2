# Лабораторная работа № 2. Spring Data JPA

## Цель работы

Разработать веб-приложение для учёта военнослужащих с использованием Spring Data JPA и базы данных H2. Приложение должно поддерживать просмотр, добавление, редактирование и удаление записей с проверкой существования сущности в базе данных.

## Архитектура проекта

- **Стек:** Java 25, Spring Boot 4.1.1, Maven, Spring MVC, Spring Data JPA, Thymeleaf.
- **СУБД:** H2 Database.
- **Основные слои:**
  - **Model** — JPA-сущность `Serviceman`, описывающая военнослужащего и структуру таблицы `servicemen`.
  - **Repository** — интерфейс `ServicemanRepository`, предоставляющий стандартные CRUD-операции и методы получения данных.
  - **Controller** — классы `HomeController` и `ServicemanController`, обрабатывающие HTTP-запросы, взаимодействующие с репозиторием и передающие данные в представления.
  - **View** — Thymeleaf-шаблоны списка, карточки и формы военнослужащего.
  - **Configuration** — класс `DataInitializer`, добавляющий демонстрационные записи при запуске приложения.
- **Ключевые аннотации:**
  - `@SpringBootApplication` — точка запуска и автоматическая конфигурация приложения.
  - `@Entity` — объявление класса как JPA-сущности.
  - `@Table` — привязка сущности к таблице базы данных.
  - `@Id` — обозначение первичного ключа.
  - `@GeneratedValue` — автоматическая генерация идентификатора.
  - `@Column` — настройка столбцов таблицы.
  - `@Controller` — объявление MVC-контроллера.
  - `@RequestMapping` — базовый адрес обработчиков контроллера.
  - `@GetMapping` — обработка GET-запросов.
  - `@PostMapping` — обработка POST-запросов.
  - `@PathVariable` — получение идентификатора из адресной строки.
  - `@ModelAttribute` — связывание данных HTML-формы с Java-объектом.
  - `@Configuration` и `@Bean` — создание конфигурации и компонента инициализации данных.
  - `@SpringBootTest` — запуск интеграционных тестов в контексте Spring Boot.

## Алгоритм работы

1. При запуске Spring Boot создаёт контекст приложения и подключается к базе H2 по адресу `jdbc:h2:mem:military`.
2. Hibernate создаёт таблицу `servicemen` на основании полей сущности `Serviceman`.
3. Если таблица пуста, `DataInitializer` добавляет несколько демонстрационных записей.
4. При переходе на `/` пользователь перенаправляется на `/servicemen`.
5. Контроллер получает все записи через `ServicemanRepository.findAll()` и передаёт их на страницу списка.
6. При открытии карточки или формы редактирования контроллер ищет запись методом `findById(id)`. Если запись отсутствует, пользователь возвращается к списку с сообщением об ошибке.
7. При добавлении данные формы преобразуются в объект `Serviceman` и сохраняются методом `save()`.
8. При редактировании контроллер сначала загружает существующую запись, обновляет её поля и сохраняет изменения. Идентификатор передаётся скрытым полем формы и не отображается пользователю.
9. Перед удалением выполняется проверка `existsById(id)`, после чего запись удаляется методом `deleteById(id)`.
10. После каждой операции пользователь перенаправляется на список или карточку военнослужащего и получает сообщение о результате.

## Данные сущности

Сущность «Военнослужащий» содержит следующие поля:

- фамилия;
- имя;
- отчество;
- национальность;
- дата рождения;
- должность;
- звание.

## Основные адреса

| Метод | Адрес | Назначение |
|---|---|---|
| `GET` | `/servicemen` | Получение и отображение всех записей |
| `GET` | `/servicemen/{id}` | Просмотр одной записи |
| `GET` | `/servicemen/new` | Открытие формы добавления |
| `POST` | `/servicemen` | Добавление записи |
| `GET` | `/servicemen/{id}/edit` | Открытие формы редактирования |
| `POST` | `/servicemen/{id}` | Сохранение изменений |
| `POST` | `/servicemen/{id}/delete` | Удаление записи |

## Запуск проекта

Для запуска необходимо выбрать JDK 25 и выполнить в корневой директории проекта:

```powershell
.\mvnw.cmd spring-boot:run
```

После запуска приложение доступно по адресу [http://localhost:8080](http://localhost:8080), а консоль H2 — по адресу [http://localhost:8080/h2-console](http://localhost:8080/h2-console).

Параметры подключения к H2:

- JDBC URL: `jdbc:h2:mem:military`;
- User Name: `sa`;
- Password: пустой.

## Проверка

